文档缺失 (4)

#1critical

README 环境部署写 python >= 3.11，但未强调 aarch64 上 torch 2.x 无 cp39 wheel、requirements.txt（numpy 2.2.6/transformers 5.0rc3/setuptools 80.10.2）均需 python>=3.10。openEuler 22.03 默认 python 3.9，初学者直接用系统 python 会在安装依赖阶段失败（No matching distribution）。

分类: python 版本门槛未强调
说明
README 环境部署写 python >= 3.11，但未强调 aarch64 上 torch 2.x 无 cp39 wheel、requirements.txt（numpy 2.2.6/transformers 5.0rc3/setuptools 80.10.2）均需 python>=3.10。openEuler 22.03 默认 python 3.9，初学者直接用系统 python 会在安装依赖阶段失败（No matching distribution）。
建议
在 README 增加"Python 3.11 必需且 aarch64 无 torch cp39 wheel"的显著提示，并给出在 openEuler 上获取 python3.11 的方法（如编译安装或 24.03 系统）
#2high

setup.py 使用 -march=armv8.2-a+sve+sve2 -flto，在 openEuler 22.03 默认 GCC 10.3.1 下 LTO 链接报 lto1: fatal error: target specific builtin not available，构建失败。README 虽写 GCC 12.3.1 已验证，但未提示 GCC 10 会失败及如何安装 GCC 12（EPOL gcc-toolset-12）。

分类: 编译器版本警告缺失
说明
setup.py 使用 -march=armv8.2-a+sve+sve2 -flto，在 openEuler 22.03 默认 GCC 10.3.1 下 LTO 链接报 lto1: fatal error: target specific builtin not available，构建失败。README 虽写 GCC 12.3.1 已验证，但未提示 GCC 10 会失败及如何安装 GCC 12（EPOL gcc-toolset-12）。
建议
在 README/环境部署章节明确"GCC 10 构建会失败（LTO+SVE2），必须 GCC 12.3.1"，并补充 openEuler 安装 GCC 12 的方法
#3medium

README 完全没有说明如何运行单元测试（test/ 下 3 个 pytest 文件）；且测试通过 import flash_engram 触发 python_wrapper 导入 torch，不装 torch 无法跑测试，文档也未说明。

分类: UT 命令缺失
说明
README 完全没有说明如何运行单元测试（test/ 下 3 个 pytest 文件）；且测试通过 import flash_engram 触发 python_wrapper 导入 torch，不装 torch 无法跑测试，文档也未说明。
建议
在 README 增加测试章节：pytest test/ -v，并注明测试运行依赖 torch
#4low

requirements.txt 将全部传递依赖精确锁定（certifi==2026.1.4 等），部分包版本（numpy 2.2.6 等）与 python3.9 不兼容，且与 torch 的 cp39 缺失叠加，导致 -r requirements.txt 必然失败。

分类: requirements.txt 与 python 版本耦合
说明
requirements.txt 将全部传递依赖精确锁定（certifi==2026.1.4 等），部分包版本（numpy 2.2.6 等）与 python3.9 不兼容，且与 torch 的 cp39 缺失叠加，导致 -r requirements.txt 必然失败。
建议
建议精简 requirements.txt 或注明 python>=3.11 硬性要求；用 >= 而非 == 以便兼容
