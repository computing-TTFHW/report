遇到的问题 (4)

容器预装 gcc/make 时误带 kernel-devel，因 /lib/modules 以只读挂载导致 dnf 写入失败（Disk Requirements 报 99MB 空间不足）

方案: 移除 kernel-devel 安装项：宿主已装匹配内核的 kernel-devel，/usr/src/kernels 已挂载进容器，无需容器重复安装

来源: 步骤 4 依赖安装

容器内 /lib/modules/$(uname -r)/build 是符号链接，指向 /usr/src/kernels/$(uname -r)，若仅挂载 /lib/modules 将无法解析构建树

方案: 同时挂载 /usr/src/kernels:/usr/src/kernels:ro，保证构建树可通过符号链接访问

来源: 构建阶段 / 容器挂载

openEuler 基础镜像默认网络 DNS 无法稳定解析仓库源，可能造成 dnf 安装失败

方案: 容器以 --network host 启动，复用宿主网络

来源: 步骤 4 依赖安装

openEuler 最小基础镜像无 insmod/rmmod（kmod 未安装），模块加载与卸载不可用

方案: dnf install -y kmod 后 insmod/rmmod 可用

来源: 步骤 6 单元测试
