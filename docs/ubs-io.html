文档缺失 (6)

#1README和部署指南未列出python3-devel为Python SDK构建的必需依赖, 仅提到python3
#2README和部署指南未提到pybind11 (pip install pybind11) 为Python SDK构建的必需依赖
#3build.sh --ut 构建需要patch命令来应用mockcpp ARM64补丁, 但文档未提及
#4build.sh使用固定-j 16并发数而非根据机器核数动态计算60%, 在256核机器上未充分利用 (build.sh line 281)
#5单元测试未通过CTest注册(add_test), 需直接运行bio_test可执行文件, 文档未说明此用法
#6部署指南配置文件示例中配置项使用完整前缀(如ubsio.mem.size_in_gb), 但样例README中未给出完整配置文件模板

遇到的问题 (4)

ubsio-kv Python SDK构建失败: CMake找不到Python3开发组件(Python3_INCLUDE_DIRS, Python3_LIBRARIES)

方案: 安装python3-devel包: dnf install -y python3-devel

来源: ubsio-kv/src/python/sdk/CMakeLists.txt:3 - find_package(Python3 COMPONENTS Interpreter Development REQUIRED)

debug UT构建失败: mockcpp ARM64补丁应用失败, patch命令不存在

方案: 安装patch包: dnf install -y patch

来源: test/tools/scripts/mockcpp.cmake:67 - execute_process(COMMAND patch -p1)

ubsio-kv Python SDK构建失败: Python模块pybind11未安装

方案: pip3 install pybind11 (安装版本3.0.4)

来源: ubsio-kv/src/python/sdk/CMakeLists.txt:7 - import pybind11

Python样例初始化失败: boostio initialize failed, ret:-1, bio server启动失败ret:2

方案: 配置文件格式错误, 配置项缺少ubsio.前缀和必要字段(wcache.evict_water_level, bdm.io_engine等). 使用仓库configs/ubsio.conf模板修正

来源: ubsio-boostio/configs/ubsio.conf - 完整配置文件模板
