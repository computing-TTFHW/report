文档缺失 (4)

#1high

quick_start 使用方式二的链接命令 gcc -O3 -o test_memcmp test_memcmp.c -L/xxx/output -lkpglibc 依赖 libkpglibc.so，但构建产物 output/ 下只有 libkpglibc_neon.so/libkpglibc_sve.so/libkpglibc_sve_950.so/libkpglibc_time.so，没有 libkpglibc.so。初学者照做会报 cannot find -lkpglibc。

分类: 命令错误
说明
quick_start 使用方式二的链接命令 gcc -O3 -o test_memcmp test_memcmp.c -L/xxx/output -lkpglibc 依赖 libkpglibc.so，但构建产物 output/ 下只有 libkpglibc_neon.so/libkpglibc_sve.so/libkpglibc_sve_950.so/libkpglibc_time.so，没有 libkpglibc.so。初学者照做会报 cannot find -lkpglibc。
建议
将命令改为 -lkpglibc_neon 或 -lkpglibc_sve_950，或提供 libkpglibc.so 的软链接（例如指向 sve_950 版本），并注明 kpglibc 不提供统一库
#2medium

README 与 installation_guide 均未给出单元测试的构建与运行命令。test/build/Makefile 的目标（func/perf/googletest/run 等）依赖 readme 提示，初学者不知道如何运行测试。

分类: UT 运行方式缺失
说明
README 与 installation_guide 均未给出单元测试的构建与运行命令。test/build/Makefile 的目标（func/perf/googletest/run 等）依赖 readme 提示，初学者不知道如何运行测试。
建议
在 README 或 docs 中补充 make -C test/build func 与 make -C test/build/functest -f Makefile.am run 的测试说明
#3low

installation_guide 的验证方式仅为 ll output 查看 so 文件，未提供调用 API 的功能性验证示例。

分类: 安装验证不完整
说明
installation_guide 的验证方式仅为 ll output 查看 so 文件，未提供调用 API 的功能性验证示例。
建议
补充一个可编译运行的 memcpy/memcmp 示例代码与预期输出
#4low

build.sh 使用 xmllint 解析 dependence.xml，但安装指南未列出该依赖；缺少 xmllint（libxml2）时 sh build.sh 会失败。

分类: 依赖说明不完整
说明
build.sh 使用 xmllint 解析 dependence.xml，但安装指南未列出该依赖；缺少 xmllint（libxml2）时 sh build.sh 会失败。
建议
在安装指南前置条件中列出 libxml2(xmllint)、cmake、gcc 等编译依赖
