#1high

分类: 依赖下载无国内镜像
说明
编译指南要求从 GitHub 下载 onnxruntime 1.22.0 与 yaml-cpp 0.8.0，实测 GitHub 直连下载停滞（onnxruntime 约 5KB/s，数分钟仅下载 2.7MB），文档未提供任何国内镜像/加速地址
建议
提供国内镜像下载地址（如 ghfast.top 等 GitHub 加速镜像），或提供 onnxruntime/yaml-cpp 的国产源（如华为云 OBS、openEuler 仓库）
#2medium

文档要求 yaml-cpp 0.8.0 从源码构建，但 openEuler 22.03 仓库提供 yaml-cpp-devel（0.6.3）可直接 dnf 安装，且用 0.6.3 也能编译通过。文档未提及更简单的 dnf 安装方式

分类: yaml-cpp 版本与获取方式
说明
文档要求 yaml-cpp 0.8.0 从源码构建，但 openEuler 22.03 仓库提供 yaml-cpp-devel（0.6.3）可直接 dnf 安装，且用 0.6.3 也能编译通过。文档未提及更简单的 dnf 安装方式
建议
在文档中说明可用 dnf install yaml-cpp-devel 替代源码构建，并注明版本差异不影响构建
#3medium
