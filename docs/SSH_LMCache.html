文档缺失 (5)

#1high

installation.rst 要求 Python 3.10-3.13，但常见 openEuler 22.03 系统自带 Python 3.9.9（requires-python 检查失败）。文档未说明需自行安装 Python 3.11+。

分类: Python 版本要求与系统不符
说明
installation.rst 要求 Python 3.10-3.13，但常见 openEuler 22.03 系统自带 Python 3.9.9（requires-python 检查失败）。文档未说明需自行安装 Python 3.11+。
建议
在安装文档补充"openEuler 系统 Python 3.9 不满足，需使用 uv/conda 安装 Python 3.11+（如 uv python install 3.11）"
#2medium

文档用 uv venv 创建环境后用 uv pip install，但对习惯 python -m pip 的用户，uv 创建的 venv 默认不含 pip，直接 pip install 会失败。文档未提示。

分类: uv venv 无 pip 陷阱
说明
文档用 uv venv 创建环境后用 uv pip install，但对习惯 python -m pip 的用户，uv 创建的 venv 默认不含 pip，直接 pip install 会失败。文档未提示。
建议
在安装文档注明 uv venv 需 python -m ensurepip 或统一使用 uv pip
#3high

文档要求 torch==2.8.0，但 pip 可能解析到 cp39 版本（本机验证装到了系统 python3.9），与 venv 的 Python 3.11 不匹配导致 import torch 失败（ModuleNotFoundError）。

分类: torch aarch64 wheel 版本陷阱
说明
文档要求 torch==2.8.0，但 pip 可能解析到 cp39 版本（本机验证装到了系统 python3.9），与 venv 的 Python 3.11 不匹配导致 import torch 失败（ModuleNotFoundError）。
建议
说明需下载匹配 Python 版本的 aarch64 wheel（cp311-cp311-manylinux_2_28_aarch64），或用 uv pip 解析到正确版本
#4medium

文档主流程需要 NVIDIA GPU + CUDA 12.8（cupy-cuda12x/nixl 等），未说明无 GPU 时可用 NO_CUDA_EXT=1 构建纯 Python 版并跳过 CUDA 依赖。

分类: 无 GPU 环境构建方式未说明
说明
文档主流程需要 NVIDIA GPU + CUDA 12.8（cupy-cuda12x/nixl 等），未说明无 GPU 时可用 NO_CUDA_EXT=1 构建纯 Python 版并跳过 CUDA 依赖。
建议
补充无 GPU/CPU 环境下安装与验证的说明（NO_CUDA_EXT=1，跳过 cupy/nixl），并说明哪些功能不可用
#5low

.pre-commit-config.yaml 含 clang-format（v20.1.3）与 mypy（language_version python3.12），但系统只有 Python 3.9/3.11，mypy 需要 python3.12 解释器，pre-commit run --all-files 会失败。

分类: clang-format/mypy 未在 README 注明运行方式
说明
.pre-commit-config.yaml 含 clang-format（v20.1.3）与 mypy（language_version python3.12），但系统只有 Python 3.9/3.11，mypy 需要 python3.12 解释器，pre-commit run --all-files 会失败。
建议
注明 mypy hook 需要 python3.12 环境，或调整 language_version 与 CI 一致

    severity
    high
    suggestion
