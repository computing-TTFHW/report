package.json 中 repository.url 指向 gitee.com/kunpeng_compute/openeuler-vscode，而当前仓库实际为 gitcode.com/openeuler/oeDevPlugin，可能导致 vsce 发布/溯源信息错误。

title
VSIX 打包未排除开发配置文件
body
.vscodeignore 未排除 .pre-commit-config.yaml、.markdownlint.yaml、.codespellrc、.devcontainer 等开发期文件，导致打包出的 VSIX 携带约 10 个非运行时文件（277.53KB，功能无影响但可精简）。

遇到的问题 (2)

docker build 时使用镜像名 oeDevPlugin-ttfhw 含大写字母，Docker 报 invalid tag 错误。

方案: 将镜像名改为小写 oedevplugin-ttfhw 后重新构建成功。

来源: docker build 命令

样例 dev:web 中 curl http://127.0.0.1:5173/ 返回 Connection refused，怀疑服务未启动。

方案: 排查发现 Vite 默认绑定 IPv6 localhost（::1），改用 curl http://localhost:5173/ 验证，返回 HTTP 200，服务正常。

来源: 样例执行（npm run dev:web）
