文档缺失 (5)

#1README.md 仅提供 uv pip install vllm 的安装方式, 未列出完整构建依赖清单 (需查阅 docs/getting_started/installation/cpu.x86.inc.md + requirements/*.txt + docker/Dockerfile.cpu)
#2Rust 前端 (vllm-rs) 的构建在 Dockerfile.cpu 中有独立 stage, 但 docs/getting_started/installation/cpu.x86.inc.md 未提及 Rust 工具链要求 (build_rust.sh 自动安装, 但开发者手动构建需知晓)
#3Docker 运行时需要 --ipc=host 或 --shm-size, 以及 --cap-add SYS_NICE --security-opt seccomp=unconfined (仅在 docs/getting_started/installation/cpu.md FAQ 中提到, 未在 Quick Start 中强调)
#4CPU 后端默认 gpu_memory_utilization=0.92 在内存受限环境 (如 8GiB WSL) 下会导致启动失败, 文档未明确说明 CPU 后端此参数的含义与推荐值
#5git safe.directory 配置在 WSL 挂载 Windows 文件系统时必需, 文档未提及

遇到的问题 (10)

docker.io 仓库不可达, docker pull ubuntu:24.04 超时

方案: 使用本地已有镜像 docker.m.daocloud.io/library/ubuntu:24.04 并 tag 为 ubuntu:24.04

tools/install_protoc.sh 因 Windows CRLF 行尾失败 (set: pipefail: invalid option name)

方案: 直接运行 curl + unzip 命令安装 protoc 34.2

Rust 前端构建超时 (vllm-rs 二进制 LTO release 编译在 2 核环境超过 20 分钟)

方案: 跳过 vllm-rs 二进制 (Rust 前端为可选, VLLM_REQUIRE_RUST_FRONTEND 默认 false). 主 setup.py 构建中 _rust_tool_parser 仍被成功编译.

git 'detected dubious ownership in repository at /workspace' 导致 setuptools-scm 无法获取版本

方案: git config --global --add safe.directory /workspace && git config --global --add safe.directory '*'

setuptools-scm git describe 在 /mnt/d (Windows 挂载) 上超时 (40s)
