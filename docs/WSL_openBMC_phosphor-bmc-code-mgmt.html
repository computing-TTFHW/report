遇到的问题 (10)

meson setup 首次执行时下载 boost(126MB) 与克隆 sdbusplus/pdi/libpldm 等 git 子项目耗时较长，超过单次命令超时

方案: 多次 reconfigure 复用 packagecache 缓存，最终完成配置

来源: subprojects/*.wrap

sdbusplus 子项目配置报错 python3 is missing modules: inflection, yaml, mako

方案: pip3 install inflection pyyaml mako

来源: subprojects/sdbusplus/meson.build:26（python.find_installation modules 检查）

Dependency systemd not found（systemd.pc 未安装）

方案: apt-get install systemd-dev（提供 systemd.pc 与 systemd_system_unit_dir 变量）

来源: meson.build:62 dependency('systemd')

libpldm 子项目报错 Meson version is 1.3.2 but project requires >=1.6.0

方案: pip3 install 'meson>=1.6.0'（升级至 meson 1.12.0）

来源: subprojects/libpldm/meson.build:15 meson_version:'>=1.6.0'

libgpiod.wrap source_hash 校验失败（kernel.org 快照 tarball 非确定性，实际 hash 与声明的 eb446070... 不符）

方案: apt-get install libgpiod-dev（系统包提供 libgpiodcxx 1.6.3，meson 优先使用系统依赖跳过该 wrap）

来源: subprojects/libgpiod.wrap

编译报错 i2c/smbus.h: No such file or directory（common/include/i2c/i2c.hpp:15）

方案: apt-get install libi2c-dev

来源: common/include/i2c/i2c.hpp:15 #include <i2c/smbus.h>

ninja 编译时 sdbus++ 工具报错 No module named 'jsonschema'（生成 pdi 接口代码失败）

方案: pip3 install jsonschema

来源: subprojects/sdbusplus/tools/sdbusplus/event.py:6 import jsonschema

events 测试链接失败：undefined reference to pldm_package_util::parsePLDMPackage 等

方案: 未修复——属仓库 test/common/events/meson.build 自身缺陷（link_with 缺少 libpldmutil），按约束不修改仓库源码，记录为失败

来源: test/common/events/meson.build

单元测试运行报错 sd_bus: org.freedesktop.DBus.Error.FileNotFound（无 D-Bus 守护进程）

方案: apt-get install dbus 并启动 dbus-daemon --system（root 下 new_bus() 调 sd_bus_open 连系统总线）

来源: subprojects/sdbusplus/src/bus.cpp:63 sd_bus_open(&b)

测试连接系统总线后报错 sd_bus_request_name: AccessDenied Permission denied（默认系统总线策略拒绝申请服务名）

方案: 部署宽松 /etc/dbus-1/system.conf（policy allow own="*"），重启 dbus-daemon --system

来源: D-Bus 系统总线默认策略 deny own
