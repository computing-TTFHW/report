文档缺失 (4)

#1high

README 仅推荐 pip install bigdl，未注明 Python 版本要求。项目文档 (docs python.md) 提到 'BigDL has been tested on Python 3.6 and 3.7'，但该信息不在 README 主入口。实际验证 Python 3.8 下 import bigdl.dllib 报 pyspark cloudpickle TypeError

分类: Python 版本要求未在 README 说明
说明
README 仅推荐 pip install bigdl，未注明 Python 版本要求。项目文档 (docs python.md) 提到 'BigDL has been tested on Python 3.6 and 3.7'，但该信息不在 README 主入口。实际验证 Python 3.8 下 import bigdl.dllib 报 pyspark cloudpickle TypeError
建议
在 README 明确 Python 3.6/3.7 要求并给 conda 创建命令 (conda create -n bigdl python=3.7)，说明 3.8+ 需升级 pyspark 或使用替代方案
#2high

bigdl-dllib 强制依赖 pyspark==2.4.6，其 cloudpickle 与 Python 3.8+ 不兼容；且 pyspark 2.4.6 有已知 CVE (log4j)。README/安装文档未提示此兼容与安全问题

分类: pyspark 2.4.6 依赖过旧
说明
bigdl-dllib 强制依赖 pyspark==2.4.6，其 cloudpickle 与 Python 3.8+ 不兼容；且 pyspark 2.4.6 有已知 CVE (log4j)。README/安装文档未提示此兼容与安全问题
建议
升级 pyspark 版本或说明使用 Python 3.6/3.7；提示 Spark 2.4 的 log4j 安全风险与升级路径
#3medium

README 标注 2026/6/30 归档、LLM 迁移至 ipex-llm，但 Orca/Nano/Chronos 等仍在 README 全面展示且无替代方案说明，初学者可能误判维护状态

分类: 项目已归档
说明
README 标注 2026/6/30 归档、LLM 迁移至 ipex-llm，但 Orca/Nano/Chronos 等仍在 README 全面展示且无替代方案说明，初学者可能误判维护状态
建议
为各子库 (Orca/Nano/Chronos/Friesian/PPML) 补充归档后的维护状态与替代方案
#4low

pip install bigdl 实际会拉取 bigdl-orca/nano/chronos/friesian/serving 及 tensorflow/torch/ray 等海量依赖，README 未提示安装体积与耗时

分类: README 安装命令隐含超大依赖
说明
pip install bigdl 实际会拉取 bigdl-orca/nano/chronos/friesian/serving 及 tensorflow/torch/ray 等海量依赖，README 未提示安装体积与耗时
建议
区分轻量安装 (如仅 bigdl-dllib) 与完整安装，并给出各子库独立安装说明
