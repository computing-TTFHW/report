文档缺失 (5)

#1教程(tutorials)即使在 interpreter 模式(TRITON_INTERPRET=1)下也在 import 时调用 triton.runtime.driver.active.get_active_torch_device() 初始化设备，纯CPU环境无法运行；README 未说明教程需GPU驱动
#2pip install -e . 在 Ubuntu 24.04 上因 PEP 668 (externally-managed) 需添加 --break-system-packages 标志，README 未提及此系统要求
#3README 未明确列出系统级构建依赖 (g++/build-essential/python3-dev/wget)，仅提及 pip 包依赖；实际构建还需 C++ 编译器和 Python 开发头文件
#4README 'Running tests' 章节说明 make test 需要 GPU，但未明确说明 make test-nogpu 可在无GPU环境完整运行 lit+cpp+前端测试
#5torch 作为教程和部分测试的依赖未在 python/requirements.txt 中列出，需单独安装 (Makefile dev-install-torch)，文档未在README中说明

遇到的问题 (2)

首次 pip install -e . 失败：Ubuntu 24.04 pip 强制 PEP 668 externally-managed environment，拒绝系统级安装

方案: 添加 --break-system-packages 标志重试 (pip install -e . --no-build-isolation --break-system-packages -v)

来源: PEP 668 / Ubuntu 24.04 Python 打包策略

向量加法教程 (01-vector-add.py) 在 TRITON_INTERPRET=1 模式下仍失败：RuntimeError: 0 active drivers — import 时调用 triton.runtime.driver.active.get_active_torch_device() 需要GPU驱动

方案: 改用专用解释器测试 (test_core.py 的 -m interpreter 标记测试) 作为样例，这些测试专为CPU/解释器设计，无需GPU驱动
