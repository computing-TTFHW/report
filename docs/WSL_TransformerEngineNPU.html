README 未指明 CANN 9.0.0 需安装 910b-ops 算子包（含 cann-hccl 组件）
body
版本表列出 CANN 9.0.0，但未说明 torch_npu 正常加载需安装 Ascend-cann-910b-ops（提供 libhccl.so 的 cann-hccl 组件）；仅安装 toolkit 时 torch_npu 报 libhccl.so 缺失，GE 图引擎初始化失败

遇到的问题 (2)

CANN 9.0.0 toolkit 安装后 torch_npu 报 ImportError: libhccl.so 缺失——CANN 9.0.0 中 libhccl.so 不再由 toolkit/hcomm 组件提供，改由 910b-ops 包内的独立 cann-hccl 组件提供

方案: 从官方 OBS 包 Ascend-cann-910b-ops_9.0.0 提取 cann-hccl_9.0.0_linux-aarch64.run 并安装到容器（--full --quiet --install-path=/usr/local/Ascend），md5 校验与宿主机一致；安装后 torch_npu 正常加载

来源: 验证环境搭建/UT 执行过程

首次运行 UT 时 CANN GE 图引擎初始化失败（FEOpsKernelInfoStore: Initialize custom and builtin sub-information library failed, GEInitializeV2 failed）——容器只装了 CANN toolkit，缺少 910b-ops 算子包，GE 无法加载算子内核信息库

方案: 从华为官方 OBS 下载 Ascend-cann-910b-ops_9.0.0_linux-aarch64.run（2.3GB）并安装到容器（--install --quiet --install-path=/usr/local/Ascend），md5 校验 c6158d29 与官方缓存一致；重跑 sanity 测试 170 passed
