文档缺失 (4)

#1medium

README 明确 DISCONTINUATION：Intel 不再维护，v7.8.0 为最后版本。文档应提示不再使用 HAXM 的原因 (Hyper-V/HVF 已替代)，避免新手新项目选型

分类: 项目已停用但保留
说明
README 明确 DISCONTINUATION：Intel 不再维护，v7.8.0 为最后版本。文档应提示不再使用 HAXM 的原因 (Hyper-V/HVF 已替代)，避免新手新项目选型
建议
在文档显著位置补充替代方案建议 (Windows 用 Hyper-V、macOS 用 HVF)，并说明归档仓库的维护状态
#2medium

manual-linux.md 只写 'Linux headers'，未说明 headers 必须与运行内核版本精确匹配。实际验证中 dnf 默认装了更新的 kernel-devel (159.4.9.163)，与运行内核 (159.4.3.154) 不匹配导致 /lib/modules/$(uname -r)/build 缺失

分类: kernel-devel 版本匹配未说明
说明
manual-linux.md 只写 'Linux headers'，未说明 headers 必须与运行内核版本精确匹配。实际验证中 dnf 默认装了更新的 kernel-devel (159.4.9.163)，与运行内核 (159.4.3.154) 不匹配导致 /lib/modules/$(uname -r)/build 缺失
建议
补充安装命令：dnf install -y kernel-devel-$(uname -r)，并说明匹配原理
#3low

make 在 core/ 源码目录直接生成 .o/.cmd 文件 (无 out-of-tree build 目录)，且 .gitignore 未完全忽略；多次构建/切换分支可能残留旧产物

分类: Linux 构建产物污染源码目录
说明
make 在 core/ 源码目录直接生成 .o/.cmd 文件 (无 out-of-tree build 目录)，且 .gitignore 未完全忽略；多次构建/切换分支可能残留旧产物
建议
改用 out-of-tree 构建 (如 make -C 或 Kbuild 的 O= 选项)，或完善 .gitignore
#4low

文档未说明 Linux 下如何验证模块功能 (需要 QEMU 创建 VM)，tests/test_emulator.cpp 仅适用 Windows/macOS

分类: Linux 测试方式缺失
说明
文档未说明 Linux 下如何验证模块功能 (需要 QEMU 创建 VM)，tests/test_emulator.cpp 仅适用 Windows/macOS
建议
补充 Linux 下的验证步骤 (insmod + QEMU 启动 guest，或提供简易 ioctl 测试工具)
