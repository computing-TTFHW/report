遇到的问题 (3)

manylinux 构建阶段出现多个 404 下载错误（EPOL-update 仓库不存在）

方案: 非致命错误，dnf 自动跳过不可用仓库继续使用其他镜像源，构建正常完成

来源: build_image.py 步骤3 manylinux Docker build

ctr_in.py 启动容器时因非交互式 SSH 导致 TTY attach 失败（exit code 1）

方案: 容器实际已成功创建并运行，使用 docker exec 代替 docker attach 进行后续操作

来源: ctr_in.py 容器启动

pre-commit 中 clang-tidy 和 gitleaks hook 因本地缺少可执行文件失败

方案: 这两个 hook 为 local 类型，需要预装 clang-tidy 二进制和 gitleaks 二进制。在完整构建环境中可用，本地 Windows 验证环境不具备。标记为环境限制而非代码问题。
