文档缺失 (5)

#1high

neural_compressor/torch/quantization/algorithm_entry.py 第321行 (repo 源码与已发布 wheel v3.9 相同): 'dynamic_shapes = model.dynamic_shapes' 无 getattr 保护。对普通 torch.nn.Module 调用 prepare() 静态量化时报 AttributeError。README 的 Getting Started 示例 (FP8 on Gaudi) 依赖类似 prepare/convert 流程，初学者照做会触发此 bug

分类: 静态量化代码 bug
说明
neural_compressor/torch/quantization/algorithm_entry.py 第321行 (repo 源码与已发布 wheel v3.9 相同): 'dynamic_shapes = model.dynamic_shapes' 无 getattr 保护。对普通 torch.nn.Module 调用 prepare() 静态量化时报 AttributeError。README 的 Getting Started 示例 (FP8 on Gaudi) 依赖类似 prepare/convert 流程，初学者照做会触发此 bug
建议
改用 getattr(model, 'dynamic_shapes', None) 或 hasattr 判断；补充仅用纯 PyTorch 模型 (无 GPTQ/ONNX 等包装) 的静态量化测试用例
#2medium

PyPI 上 neural-compressor-pt 3.9 的 Requires 列表只有 numpy/packaging/prettytable/psutil/py-cpuinfo/pydantic/torchao，未含 torch。README 说 'pip install neural-compressor-pt' 但装完 import 仍缺 torch，需手动安装

分类: neural-compressor-pt wheel 未声明 torch 依赖
说明
PyPI 上 neural-compressor-pt 3.9 的 Requires 列表只有 numpy/packaging/prettytable/psutil/py-cpuinfo/pydantic/torchao，未含 torch。README 说 'pip install neural-compressor-pt' 但装完 import 仍缺 torch，需手动安装
建议
在 wheel 依赖中声明 torch (或 torch 相关 extra)，并在 README 明确 torch/ipex 需单独安装
#3medium

SmoothQuant 等算法需要 intel_extension_for_pytorch，README 安装章节有说明但入门示例 (Getting Started) 未提醒；初学者按示例运行会报 ModuleNotFoundError

分类: SmoothQuant 等依赖未自动安装
说明
SmoothQuant 等算法需要 intel_extension_for_pytorch，README 安装章节有说明但入门示例 (Getting Started) 未提醒；初学者按示例运行会报 ModuleNotFoundError
建议
在 Getting Started 示例前注明所需额外依赖，或提供 requirements-dev/requirements-test 清单
#4low

Ubuntu 22.04 的 python3.11 是 3.11.0rc1 (发布候选)，与 torch 2.13 不兼容 (缺 sys.get_int_max_str_digits)。文档只写 Python >=3.11，未提示需正式发布版 Python

分类: Ubuntu 自带 Python 3.11 为 RC
说明

建议
建议使用 python:3.11-slim 镜像或死蛇 PPA 安装正式版 3.11
