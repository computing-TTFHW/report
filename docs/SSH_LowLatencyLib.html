文档缺失 (4)

#1medium

test_whitelist.c 运行提示 'Pass/fail is determined by run_all.sh via debug log analysis'，但 run_all.sh 未随仓库提供（find 全仓库仅有 build_and_package.sh）。初学者无法按说明完成测试。

分类: 测试运行方式缺失
说明
test_whitelist.c 运行提示 'Pass/fail is determined by run_all.sh via debug log analysis'，但 run_all.sh 未随仓库提供（find 全仓库仅有 build_and_package.sh）。初学者无法按说明完成测试。
建议
补全 run_all.sh，或在 README 说明各 wl 用例的判定标准与手动运行方法。
#2low

README 的 make install 写死 sudo cp /usr/local/lib/，在 root 环境或权限受限环境会失败。

分类: make install 依赖 sudo
说明
README 的 make install 写死 sudo cp /usr/local/lib/，在 root 环境或权限受限环境会失败。
建议
将 Makefile install target 的 sudo 改为可配置（如 DESTDIR），并在 README 说明非 root 用法。
#3low

test_whitelist.c 各用例即使失败也可能返回 0（判定依赖 debug 日志解析），直接运行无法从退出码判断通过与否。

分类: 测试无退出码校验
说明
test_whitelist.c 各用例即使失败也可能返回 0（判定依赖 debug 日志解析），直接运行无法从退出码判断通过与否。
建议
让测试用例返回明确的非零退出码，或补充可脚本化的断言输出。
#4low

仓库文档仅有中文（README.md、cond/docs/constraints_des.md），对非中文用户不友好。

分类: README 与 constraints 文档均为中文
说明
仓库文档仅有中文（README.md、cond/docs/constraints_des.md），对非中文用户不友好。
建议
补充英文版 README_EN.md。
