分类: OS/环境说明缺失
说明
README 未说明推荐的操作系统和字体安装前置条件；UFO 源编辑需要 RoboFont 4.4（macOS 专属 GUI 软件），但文档未说明 Linux 下如何编辑或构建字体
建议
在 README 增加环境要求章节，说明推荐 OS（如 Ubuntu/openEuler）、Linux 下可用的替代工具（如 fontmake/fonttools 命令行构建），或提供命令行构建脚本
#2medium

README 的 Generating Fonts 章节只描述 RoboFont GUI 操作，初学者在 Linux/CI 环境中无法复现从 UFO 源到 OTF/TTF 的构建流程

分类: 无命令行构建入口
说明
README 的 Generating Fonts 章节只描述 RoboFont GUI 操作，初学者在 Linux/CI 环境中无法复现从 UFO 源到 OTF/TTF 的构建流程
建议
提供 fontmake / fontTools 的命令行构建命令，或提供 Makefile/CI 工作流示例（如 .github/workflows/build.yml）
#3low

README 提到 postscript 源用于 OTF、TrueType 源用于 TTF/WOFF，但未提供一步到位的构建说明，且 masters 仅 postscript 格式（插值后需 QuadraticConverter 转 TrueType）

分类: 源文件与成品对应关系
说明
README 提到 postscript 源用于 OTF、TrueType 源用于 TTF/WOFF，但未提供一步到位的构建说明，且 masters 仅 postscript 格式（插值后需 QuadraticConverter 转 TrueType）
建议
补充从 masters 插值到各 weight/italic 的完整命令链示例
#4low

构建流程依赖 RoboFont、Skateboard、DesignSpaceEditor、QuadraticConverter、Microsoft VTT 等外部商业/专有工具，其中部分需付费或仅支持特定平台

分类: 外部工具依赖
说明
构建流程依赖 RoboFont、Skateboard、DesignSpaceEditor、QuadraticConverter、Microsoft VTT 等外部商业/专有工具，其中部分需付费或仅支持特定平台
建议
说明替代的开源工具链（fontmake、fonttools、vttcompile 等）以降低入门门槛
