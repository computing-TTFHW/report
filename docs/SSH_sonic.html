文档缺失 (4)

#1critical

commit ba8b7aa（update sonic arm version）中 internal/native/sse/native_export.go、internal/native/avx2/native_export.go、internal/decoder/jitdec/asm_stubs_amd64_go121.go 等 amd64 专用文件缺少 amd64 build 标签，导致 arm64 上 go build ./... 直接失败。

分类: arm64 构建缺陷（amd64 包未隔离）
说明
commit ba8b7aa（update sonic arm version）中 internal/native/sse/native_export.go、internal/native/avx2/native_export.go、internal/decoder/jitdec/asm_stubs_amd64_go121.go 等 amd64 专用文件缺少 amd64 build 标签，导致 arm64 上 go build ./... 直接失败。
建议
为这些文件补充 //go:build amd64（或给 jitdec 包整体加 amd64 约束）；在 CI 增加 arm64 go build ./... 校验。
#2medium

README 只有 API 与 benchmark，没有 'How to build/test' 章节；arm64 的构建注意事项（go1.20+、GOPROXY、排除 amd64 包）均未说明。

分类: README 未提供构建/测试命令
说明
README 只有 API 与 benchmark，没有 'How to build/test' 章节；arm64 的构建注意事项（go1.20+、GOPROXY、排除 amd64 包）均未说明。
建议
增加安装/构建/测试章节，明确 go1.20+（ARM64）、GOPROXY 设置及 go test 的包排除写法。
#3low

README 说支持 Go 1.18~1.26 且 Go1.24.0 不支持，但未说明 build-arm.sh 生成的 neon 汇编需要特定 Go（funcdata_go117/118/120/121/123/126.go 分版本），初学者无法判断版本搭配。

分类: Go 版本矩阵说明不全
说明
README 说支持 Go 1.18~1.26 且 Go1.24.0 不支持，但未说明 build-arm.sh 生成的 neon 汇编需要特定 Go（funcdata_go117/118/120/121/123/126.go 分版本），初学者无法判断版本搭配。
