文档缺失 (4)

#1high

released wheel intel-extension-for-transformers 1.4.2 的 transformers/neural_chat 模块引用 'from neural_compressor.conf.config import ...'，但 pip 自动安装的 neural-compressor 3.7.1 已无 conf 模块 (改为顶层 config.py)。README 的 'pip install intel-extension-for-transformers' 快速安装路径装完核心 API 无法使用

分类: 依赖版本不兼容
说明
released wheel intel-extension-for-transformers 1.4.2 的 transformers/neural_chat 模块引用 'from neural_compressor.conf.config import ...'，但 pip 自动安装的 neural-compressor 3.7.1 已无 conf 模块 (改为顶层 config.py)。README 的 'pip install intel-extension-for-transformers' 快速安装路径装完核心 API 无法使用
建议
修正 wheel 依赖版本约束 (如 neural-compressor<2.x 或适配 3.x API)，或在 README 明确兼容的 neural_compressor 版本
#2high

requirements-cpu.txt 固定 torch==2.3.0+cpu，但 pip 解析 transformers 时安装了 5.15.0 (要求 torch>=2.5)，运行时 transformers 报 'Disabling PyTorch because PyTorch >= 2.5 is required'，模型功能不可用

分类: transformers 版本与 torch 不匹配
说明
requirements-cpu.txt 固定 torch==2.3.0+cpu，但 pip 解析 transformers 时安装了 5.15.0 (要求 torch>=2.5)，运行时 transformers 报 'Disabling PyTorch because PyTorch >= 2.5 is required'，模型功能不可用
建议
固定 transformers 版本 (如 <5) 或升级 torch，并补充版本兼容矩阵
#3medium

setup.py 使用 CMakeExtension 编译 C++ 内核，依赖 15+ git 子模块 (oneDNN/yaml-cpp/pybind11/boost 等)，README 未说明需 git clone --recursive / submodule update，浅克隆后源码构建必然失败

分类: 源码构建子模块未说明
说明
setup.py 使用 CMakeExtension 编译 C++ 内核，依赖 15+ git 子模块 (oneDNN/yaml-cpp/pybind11/boost 等)，README 未说明需 git clone --recursive / submodule update，浅克隆后源码构建必然失败
建议
README 补充源码构建说明 (git submodule update --init --recursive + pip install -e .)
#4medium

README 使用 intel_extension_for_transformers.optimization / transformers.modeling 等 API 路径，与 released wheel 1.4.2 的实际模块结构 (transformers/neural_chat/qbits) 不完全一致

分类: README API 示例过时
说明
README 使用 intel_extension_for_transformers.optimization / transformers.modeling 等 API 路径，与 released wheel 1.4.2 的实际模块结构 (transformers/neural_chat/qbits) 不完全一致
建议
同步 README 示例与实际 wheel API，或提供 examples/ 的一键运行脚本
