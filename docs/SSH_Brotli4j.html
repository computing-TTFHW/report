文档缺失 (4)

#1medium

README.md 只给出 Maven/Gradle 使用方式（依赖坐标），没有 'Build from source' 章节说明 mvn clean package 与平台原生库编译流程。初学者无法从 README 得知如何本地构建。

分类: README 无从源码构建说明
说明
README.md 只给出 Maven/Gradle 使用方式（依赖坐标），没有 'Build from source' 章节说明 mvn clean package 与平台原生库编译流程。初学者无法从 README 得知如何本地构建。
建议
在 README 增加 'Building from source' 章节：mvn -B clean package，说明 natives/* 模块按 OS/arch profile 自动构建原生库。
#2low

pom.xml 目标编译版本为 1.8（maven.compiler.release=8），但 README 未说明需要 JDK 1.8 及以上；Dockerfile 用 JDK8，而 CI 覆盖 JDK8-21。新手可能用更老或过新的 JDK。

分类: JDK 版本要求说明不明确
说明
pom.xml 目标编译版本为 1.8（maven.compiler.release=8），但 README 未说明需要 JDK 1.8 及以上；Dockerfile 用 JDK8，而 CI 覆盖 JDK8-21。新手可能用更老或过新的 JDK。
建议
在 README 注明需要 JDK 1.8+，并提示 jdk9+ profile 会设置 maven.compiler.release=8。
#3medium

docker/Dockerfile*.centos6 基于已 EOL 的 CentOS 6（gatlingcorp/centos:6-gcc5），yum 源可能失效；且 Dockerfile 内 wget maven/cmake 从外网下载，国内网络可能失败。

分类: 构建镜像使用 EOL 的 CentOS 6
说明
docker/Dockerfile*.centos6 基于已 EOL 的 CentOS 6（gatlingcorp/centos:6-gcc5），yum 源可能失效；且 Dockerfile 内 wget maven/cmake 从外网下载，国内网络可能失败。
建议
更新 Dockerfile 到 CentOS 7/8 或 Ubuntu 22.04，并使用国内镜像源；或删除陈旧的 centos6 系列 docker-compose*11/17/21.yml。
#4medium

v1.20 中 Decoder.decompress 返回 DirectDecompress（需 getDecompressedData()），README 的示例仍按旧 API 展示，照抄会编译报错 incompatible types。

分类: Decoder API 变更未在 README 体现
说明
v1.20 中 Decoder.decompress 返回 DirectDecompress（需 getDecompressedData()），README 的示例仍按旧 API 展示，照抄会编译报错 incompatible types。
建议
更新 README 示例代码匹配当前 API，或注明返回类型。
