编译 cs_tcp.c 时 fatal error: numa.h: No such file or directory

方案: dnf install -y numactl-devel（openEuler 官方仓库）后清理 CMake 缓存并重试编译

来源: pkg/src/protocol/cs_tcp.c:28

方案: chown/chmod /home/ogracdba 后重试安装（未改源码）

来源: install.py / installdb.sh 日志重定向

来源: install.py 以 su - ogracdba 调用 installdb.sh

来源: CI/build/script/run_ograc_test.sh 安装路径
